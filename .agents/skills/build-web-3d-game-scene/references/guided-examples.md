# 引導對話範例

用選項和推薦幫使用者做決定。依已知答案調整順序，每一輪只處理一個主要決定。以下六則訊息是同一段對話中的不同輪次。

**使用者**：我想做一個網頁 3D 遊戲場景，但還沒有想法。

**助理**：你想做哪一類 3D 場景？

1. 第一人稱探索（推薦），從能走動、碰撞與查看道具的小關卡開始。
2. 第一人稱射擊（FPS），做一個具備清楚空間輪廓和地標的關卡。
3. 平台跳躍，從測試平台高度、距離和落點開始。

可以回編號、「用推薦」，或描述你想做的其他類型。

**使用者**：2。

**助理**：這個 FPS 關卡要放在哪裡？

1. 廢墟巷弄（推薦），從一條紅磚巷通往小廣場，兩個空間就能先做出完整原型。
2. 廢棄工業倉庫，從卸貨門進到主樓層，貨架和挑高屋頂突出尺度。
3. 封閉車站大廳，從售票區通向月台入口，以招牌和燈光標示方向。

**使用者**：1。

**助理**：你偏好哪種廢墟巷弄的畫面？

1. **低多邊形｜低，推薦給第一次做的組別**。碎石和缺角牆用清楚的幾何輪廓表現，容易延用灰盒和搭配免費道具。
2. **風格化半寫實｜中**。用裸露紅磚、灰泥和舊鐵門帶出材質，需要統一貼圖尺度與光照。
3. **PS1 復古｜低至中**。低解析度貼圖加薄霧就能開始。像素化效果和頂點抖動會增加渲染工作。

**後續做法**

- 使用者回答「用推薦」時，採用低多邊形，並在需要時問想要提示詞、場景設計還是直接實作。
- 若使用者一開始就說「做 FPS 廢墟巷弄，已確定風格化半寫實，請給提示詞」，直接交付可複製的提示詞，附上該風格的技術重點。
- 若使用者請你全部代選，採用「第一人稱探索、小型場景、低多邊形、單一互動」作為入門組合。若已指定 FPS，沿用 FPS 和適合該目標的場景，保留用來驗證場景的簡單互動。
