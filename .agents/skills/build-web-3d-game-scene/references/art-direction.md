# 美術風格與第一人稱場景範例

用造型、材質和渲染方式選擇美術風格。依場景主題另選光線、天候與色彩。未指定風格時，小型教學原型可採低多邊形，需要建築質感時可採風格化半寫實。換風格時，使用同一路線和第一人稱視角比較可讀性。

難度以一人使用 Three.js 製作小型瀏覽器關卡為基準，涵蓋美術素材、渲染和效能。說明會讓難度提高或降低的條件，例如是否已有統一風格的素材包，以及是否需要後製效果。

| 風格 | 技術難度 | 廢墟巷弄的處理方式 | 主要技術成本 |
|---|---|---|---|
| 低多邊形（Low Poly） | 低 | 缺角牆面、塊狀碎石、大面積色塊 | 基本幾何與簡單材質就能做出第一版。主要花時間統一模型比例和輪廓。 |
| 風格化半寫實（Stylized Semi-realistic） | 中 | 寫實比例、裸露紅磚、灰泥和斑駁鐵皮 | 需要統一貼圖尺度、材質細節與光線。可把高細節留給近處與地標。 |
| 寫實 PBR（Realistic PBR） | 高 | 水漬、不同粗糙度的混凝土和鏽蝕金屬 | 需要相近品質的貼圖、光照及反射。預留測試貼圖記憶體和瀏覽器效能的時間。 |
| PS1 復古風 | 低至中 | 低解析度貼圖、稜角輪廓、遠處薄霧 | 基本版用簡化模型、低解析度貼圖及霧效即可。加入像素化或頂點抖動會增加渲染及驗收工作。 |
| 賽璐璐／漫畫風（Cel-shaded） | 中 | 描邊、階梯式明暗色塊、手繪招牌 | 需要一致的陰影分階。全場描邊會增加渲染成本，尤其要檢查物件交疊與遠近粗細。 |
| 體素風（Voxel） | 低至中 | 牆磚、窗洞及碎塊沿格點堆疊 | 建模單純。方塊很多時，需用重複實例或合併幾何控制繪製成本。 |

## 範例需求

> 在網頁第一人稱射擊遊戲裡，做一個風格化半寫實的虛構廢墟巷弄。玩家從紅磚巷走進小廣場，用灰藍色招牌與暖色路燈辨識方向。用 Three.js 搭主要空間與碰撞，用 Three-Live 製作參數化破牆。有合適的免費 GLB 時再加入街道道具。用靠近舊招牌按 E 顯示提示作為場景驗收互動。

### 把需求落到場景

- 取景依序涵蓋出生點、紅磚巷的轉角和廣場入口。灰盒先確認門洞、地面高差、照明位置，再加入破牆、舊窗框、鐵捲門和碎石。
- 採混凝土灰、褪色磚紅與灰藍。用柔和的陰天光照出牆體，廣場入口以一盞暖色路燈標示。僅在遠處加薄霧，以第一人稱畫面確認近處地形可見。
- 為 Three-Live 矮牆提供 `width`、`height` 和 `gapOffset` 等參數。碰撞由遊戲依可通行空間配置。廣場道具可優先找低多邊形路燈、花盆或金屬招牌，選擇已確認能合法取得的版本。
- 驗收時從出生點走到廣場，試一次牆面碰撞和招牌互動，確認破牆缺口的外觀、通行規則與碰撞一致，並從三個視點檢查地標。
