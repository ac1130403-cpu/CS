# Neon Foundry

霓虹科幻風格的 3D 第一人稱射擊網頁遊戲原型。

## 操作
- WASD：移動
- 滑鼠：轉向與瞄準
- 左鍵：射擊
- R：裝填
- Esc：釋放滑鼠

## 執行
在專案資料夾執行：

```powershell
python -m http.server 8080
```

然後開啟 `http://localhost:8080/`。

## 功能
- 第一人稱移動與滑鼠鎖定
- 工業倉庫場景與牆面碰撞
- 射擊、生命、彈藥、敵人與勝負流程
- 霓虹燈光、霧效與簡單命中效果
- 沒有人體角色；敵人是會移動的機械守衛

## 素材
場景與角色均由 Three.js 基本幾何即時建立，未使用外部素材。
